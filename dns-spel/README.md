# DNS-spel · Windows System Administration (HOGENT)

Mobiele oefeningen bij de les **DNS op Windows Server** (CampusConnect-labo).

| Oefening | Hoort bij dia | Wat |
|---|---|---|
| Welk record? | 13 | Stemkaart voor de klas + 10 oefensituaties |
| FQDN-puzzel | 10 | FQDN bouwen, delen benoemen, zone-vraag |
| Voorspel de uitvoer | 23, 34 | Exitcheck blok 1 en begripscheck 2 |
| Het querypad | 15–18, 21 | Simulatie van 5 rondes met live TTL-cache |

Statische site: geen build, geen server, geen tracking. Resultaten blijven alleen in de browser van de student (localStorage).

## Publicatie
