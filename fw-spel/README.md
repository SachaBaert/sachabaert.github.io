# FW-spel · Windows System Administration (HOGENT)

Mobiele oefeningen bij de les **Netwerksegmentatie met pfSense** (labo SRV01 · CLIENT01 · pfSense · cursus.local; SERVER 192.168.10.0/24, CLIENT 192.168.20.0/24).

| Oefening | Route | Wat |
|---|---|---|
| Sorteer / stemkaart | `#/sorteer/<set>`, `#/kaart/<set>` | lokaal, interface, rol, laag |
| Ontwerp het netwerk | `#/ontwerp` | Adresplan op de tekening + ontwerpvragen |
| Volg het pakket | `#/pakket` | Ping en DHCP-relay in volgorde |
| Exitcheck | `#/exit1`, `#/exit2` | Blok 1 en blok 2 |
| Lees de regel | `#/regel` | Interface, volgorde, stateful, Apply |
| Lees de uitvoer | `#/uitvoer` | ipconfig, ping, arp, Test-NetConnection, firewalllog |
| Welk bewijs? | `#/bewijs` | Begripscheck |
| Voorspel de demo | `#/demo`, `#/demo/<n>` | Voorspellingen 1–10 bij demo's 1–8 |
| Labo klaarzetten | `#/labo` | FW_labo_student.ps1 met kopieerknop |
| Werkdoel · Status · Foutenpracticum · Ticket · Exit ticket | `#/werkdoel`, `#/status`, `#/fout`, `#/ticket`, `#/exitticket` | Namiddag |
| Extra oefenen | `#/extra/<onderwerp>` | 10 uit 30: segmentatie, pfsense, firewall, dhcp, trouble |

Statische site: geen build, geen server, geen tracking. Resultaten blijven alleen in de browser (localStorage, prefix `fw.`).

Online: https://sachabaert.github.io/fw-spel/
