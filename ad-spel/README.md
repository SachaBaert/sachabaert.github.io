# AD-spel · Windows System Administration (HOGENT)

Mobiele oefeningen bij de les **Active Directory Domain Services** (labo DC01 · CLIENT01 · ad.brightlearning.test).

| Oefening | Route | Wat |
|---|---|---|
| Sorteer | `#/sorteer/<set>`, `#/kaart/<set>` | Stemkaart + oefenen: lokaal, begrip, auth, jml, cu |
| Teken de infrastructuur | `#/schema` | Begripscheck 1 |
| AGDLP-keten | `#/agdlp` | Volgorde, bereik, toegang |
| Exitcheck blok 1 | `#/exit1` | DNS, OU, groepen, delegatie |
| Diagnosepad | `#/diag` | Go/no-go vóór de domain join |
| Lees de uitvoer | `#/uitvoer` | ipconfig, nslookup, nltest, whoami, gpresult |
| Welk bewijs? | `#/bewijs` | Begripscheck 2 |
| GPO-scope | `#/gposcope` | Scope, LSDOU, Enforced, Block Inheritance |
| Voorspel de demo | `#/demo`, `#/demo/<n>` | Demo's 1–13 |
| Werkdoel · Status · Foutenpracticum · Ticket · Exit ticket | `#/werkdoel`, `#/status`, `#/fout`, `#/ticket`, `#/exitticket` | Namiddag |
| Extra oefenen | `#/extra/<onderwerp>` | 10 uit 30 per onderwerp |

Statische site: geen build, geen server, geen tracking. Resultaten blijven alleen in de browser (localStorage, prefix `ad.`).

Online: https://sachabaert.github.io/ad-spel/
